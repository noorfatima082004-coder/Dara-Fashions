# Dara — Pakistani Fashion

A mobile-first e-commerce frontend for **Dara**, inspired by premium Pakistani fashion brands.

## Screens

- **Splash** — Brand intro with tagline
- **Home** — Hero banner, category grid, USP bar, new arrivals
- **Categories** — Featured & secondary category browsing
- **Product Listing** — Filterable grid with tabs (Shirts)
- **Product Detail** — Color/size selection, add to bag
- **Shopping Bag** — Cart management with checkout summary

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser. The app is designed for mobile viewport (max 430px) — use browser dev tools mobile emulation for the best experience.

## Design

- **Colors:** Black, white, tan (`#C5A377`), light gray
- **Typography:** Cormorant Garamond (serif headings) + Inter (body)
- **Layout:** Mobile-first, max-width 430px centered
